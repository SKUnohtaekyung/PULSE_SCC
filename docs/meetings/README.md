# 회의록

팀 회의와 멘토 회의 기록을 둔다. **신청서 ⑦이 주 1회 팀 회의와 격주 멘토 회의를 약속했고, 지금 그 기록이 하나도 없다.**

## 규칙

- 파일명: `YYYY-MM-DD-<team|mentor>.md` (예: `2026-08-26-mentor.md`)
- 멘토·팀원 실명은 써도 되지만 **연락처·학번은 쓰지 않는다**
- **결정한 것과 아직 논의 중인 것을 구분한다.** 이 구분이 없으면 나중에 "그때 정했다"는 착각이 생긴다
- 되돌리기 어려운 결정이 나오면 회의록에만 두지 말고 [ADR](../decisions/)로 승격한다

## 회의록이 하는 일

Handoff는 작업 인수인계, ADR은 결정 근거, 회의록은 **언제 누가 무엇을 논의했는가**의 기록이다. 셋은 다르다.

- 회의에서 정한 것 중 **장기적으로 유효한 결정** → ADR
- 회의에서 나온 **작업 지시** → 이슈 또는 Handoff
- 회의록 자체는 **그 시점의 상태를 남기는 것**이 목적이다
