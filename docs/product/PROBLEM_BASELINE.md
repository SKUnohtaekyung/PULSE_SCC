**이 문서는 "우리가 신청서에 쓴 것 중 무엇이 근거로 버티고 무엇이 안 버티는가"의 정본이다.**

| | |
|---|---|
| 상태 | 대조 완료 / 현장 1차 자료 **미확보** |
| 최종 수정 | 2026-08-21 |
| 소유 역할 | `role:product` |
| 대조 대상 A | [docs/program/APPLICATION_F12.md](../program/APPLICATION_F12.md) — 2026-06-28 공식 약속 |
| 대조 대상 B | [FINAL_RESEARCH_REPORT.md](../../FINAL_RESEARCH_REPORT.md) — 2026-08-21 공식 통계 검증, 판정 **D** |

> **이 문서는 [PRD.md](PRD.md) 를 대체하지 않는다.** PRD는 "무엇을 만들 것인가"의 정본이고,
> 이 문서는 그 앞단인 "문제 정의가 근거로 지지되는가"만 다룬다.
> 현장 인터뷰 결과가 나오면 PRD 2·5·9장을 이 문서를 근거로 채운다.

> ⚠️ **신청서 본문은 바꾸지 않는다.** 이미 대외 제출된 공식 문서다.
> 발표·보고서에서 수치를 인용할 때 이 문서의 판정을 따른다.

## 2. 신청서 주장 대조표 ★

신청서 ①에 적은 6개 근거·주장을 검증 결과와 대조한다.

### 2.1 폐업률·생존율 — ✅ 유지

| | |
|---|---|
| 신청서 | 숙박·음식점업 5년 생존율 20.5%, 음식업 폐업률 16.2%(전 업종 9.0%), 폐업 사유 1위 사업부진 48.9% |
| 검증 | **PASS.** 20.5%는 통계청 기업생멸행정통계 전수 행정자료, S급 원문 확인〔E-A13〕. 전산업 평균 31.2%와 10.7%p 차이 |
| 단서 | 20.5%는 **대분류 I(숙박업 포함)** 기준이다. "음식점 및 주점업(KSIC 56)" 단독 생존율은 통계청이 공표하지 않아 **확인 실패**했다. 발표에서 "음식점 5곳 중 4곳"이라고 말하려면 이 정의 차이를 같이 말해야 한다 |
| 보강 | 2024년 기준 외식업체 평균 영업이익률 **8.7%**(2022년 조사 11.6%에서 하락), 외식산업경기동향지수 2026년 2분기 **78.82**〔E-N207·E-N210, A급〕 — 신청서보다 최신이고 더 강한 근거다 |

### 2.2 "리뷰 항상 확인 80.3%" — ❌ 사용 중지

| | |
|---|---|
| 신청서 | 엠브레인 트렌드모니터, 리뷰 항상 확인 80.3% |
| 검증 | **80.3%라는 수치 자체의 원문을 확인하지 못했다.** 같은 기관(엠브레인 트렌드모니터)의 인접 수치(리뷰 필요 86.9%, 경험자 리뷰 신뢰 69.3%)는 **2017년 조사 + 언론 재인용 + 음식점 한정 아님**으로 [rejected_sources.md](../../research/rejected_sources.md) 에서 근거 제외 판정됐다 |
| 대체 | 한국소비자원 「배달 플랫폼 리뷰 실태조사」(2024.7) — **배달앱 이용자의 73.4%** 가 음식점·메뉴 선택 시 리뷰 참고〔E-B01〕 |
| 반드시 함께 | 모집단이 **배달앱 이용자 1,000명**이다. 매장 방문 중심 소비자 전체를 포괄하는 국가승인통계는 **존재하지 않는다** |

### 2.3 "사장님의 문제는 마케팅·고객 이해" — 🔴 정면 반박

| | |
|---|---|
| 신청서 | 사장님이 리뷰를 분석해 활용할 시간·전문지식이 부족한 것이 핵심 문제 |
| 검증 | 숙박·음식점업 소상공인 경영애로 순위: **1위 원재료비 73.9%, 2위 경쟁심화 62.4%**. 마케팅에 가장 가까운 **"판로개척 및 운영"은 3.4%로 11개 항목 중 8위**. 전산업 평균 16.0%, 제조업 29.8%와 비교하면 외식업에서 유독 낮다 |
| 보강 반박 | 숙박·음식점업 디지털 기술 활용은 매장관리 46.7%, 스마트 주문·결제 43.3%인 반면 **디지털 광고는 1.6%**(전산업 6.5%) |
| 처리 | 이것이 판정 D의 첫 번째 이유다. **"사장님이 원한다"가 아니라 "검증할 가설"로만 표현한다.** 인터뷰(§5)가 이 항목을 직접 겨냥해야 한다 |

### 2.4 "만안구가 침체됐다 (14,938 vs 21,047)" — ⚠️ 수치 교체

| | |
|---|---|
| 신청서 | 만안구는 동안구 대비 사업체 수 약 71% 수준(14,938 vs 21,047)인 원도심 |
| 문제 | 그 수치는 **2025년 경제총조사 '조사대상' 사업체, 전 산업 기준, 언론 인용**〔E-D02, C~D급〕이다. 음식점업 수치가 아니다 |
| 교체값 | 통계청 전국사업체조사 안양시 집계분(국가승인통계 제210003호, **2024년 기준**, 안양시청 첨부 엑셀 원본, 독립 검증자가 셀 단위 재확인) |

| 산업분류 | 안양시 | 만안구 | 동안구 |
|---|---|---|---|
| 56. 음식점 및 주점업 | 7,173개 / 21,234명 | **3,175 / 8,345** | 3,998 / 12,889 |
| 561. 음식점업 | 4,743개 / 15,316명 | 2,052 / 5,855 | 2,691 / 9,461 |

- 음식점업 기준 만안/동안 비율은 71%가 아니라 **약 79%** 다. 신청서보다 격차가 작다.
- **"만안구 상권이 침체됐다"는 주장의 공식 근거는 없다.** 안양시 단위 외식업 경영난 조사 자체가 존재하지 않는다.
- 🔎 **다만 쓸 수 있는 신호가 하나 있다.** 위 표에서 유도하면 음식점·주점업 **업체당 종사자 수가 만안구 2.63명, 동안구 3.22명**이다. "만안구 외식업체가 동안구보다 평균적으로 작다(영세하다)"는 근거로 쓸 수 있다. **단, 원자료에 공표된 수치가 아니라 우리가 계산한 값이므로 그렇게 표기한다.**
- ❓ **확인 필요:** 안양시 행정동별 음식점업 상위 10곳은 인덕원동 762, 범계동 483, 관양동 475, 부림동 466, 안양1동 455, 안양4동 377, 안양6동 361, 안양3동 280, 안양7동 274, 안양2동 273이다. **명학역이 속한 행정동이 이 목록에 있는지 확인하지 않았다.** 없다면 "명학역 인근"은 만안구 안에서도 주력 외식 상권이 아니다. 발표 전에 반드시 확인한다

### 2.5 리뷰 수집 경로 — 🔴 봉쇄

| | |
|---|---|
| 신청서 | 가게의 온라인 리뷰 텍스트를 입력받아 AI로 분석 |
| 검증 | 네이버 지도·카카오맵 robots.txt 모두 최상단에 **"AI 학습 및 RAG 목적의 봇 접근을 엄격히 금지"** 를 명시하고 ClaudeBot·GPTBot 등을 개별 차단하며 전 경로에 `Disallow: /` 를 적용한다. 네이버 이용약관도 자동화 수단에 의한 게시물 수집을 금지한다. **카카오는 리뷰를 오픈API·제휴 어느 쪽으로도 제공하지 않는다고 공식 답변했다** |
| 심각도 | 이 프로젝트의 용도(AI·RAG)를 **콕 집어** 금지한다. 우회 설계가 없으면 원재료 자체가 없다 |
| 가능한 경로 | ① 사장님 동의를 받은 리뷰 데이터 ② 사장님 **본인 계정 연동** 기반 수집으로 구조 전환 ③ 공식 API·공개 데이터셋 ④ 약관을 준수한 소량 수기 수집 ⑤ 발표용 예시 데이터는 실제 데이터와 명확히 구분 |
| 처리 | **ADR로 확정해야 한다.** 중간간담회에서 반드시 질문받을 지점이다 |

### 2.6 "리뷰로 대표 손님 유형(페르소나)을 도출" — 🔴 근거 없음

| | |
|---|---|
| 신청서 | 리뷰 분석으로 대표 손님 유형(페르소나) 카드와 고객여정 지도를 출력 |
| 검증 | **리뷰로 고객의 연령·성별·직업을 알 수 있다는 국내 공식·학술 근거는 존재하지 않는다.** 페르소나 방법론 자체도 "몇 명의 실제 사용자를 대표하는지 검증 불가능하다"는 학술적 비판을 받아 왔다 |
| 대표성 반박 | 같은 KCA 조사에서 리뷰 작성자의 **65.2%가 리뷰이벤트 참여를 작성 이유**로 꼽았고, 이벤트 참여자의 **98.3%가 실제 만족도보다 별점을 높게 줬다**고 답했다. 국제 학술 문헌의 J자형 분포·자기선택 편향과도 정합적이다 |
| 처리 | "대표 손님 유형"을 **인구통계 페르소나로 제시하지 않는다.** 리뷰에서 실제로 나오는 것은 **반복되는 의견의 주제·감정**이다. 산출물 정의를 여기에 맞춰 축소·한정한다 |

### 2.7 "리뷰 분석이 우리 차별점" — 🔴 이미 무료로 존재

| 서비스 | 제공 |
|---|---|
| aT 「The외식 나침반」 | 포털 리뷰를 분석해 매장 강점·보완점 제시. **정부 예산으로 무료** |
| 네이버 스마트플레이스 '온서비스 AI' | 부정 리뷰 감지·알림 + 답글 초안 생성. 2025.12 발표, 베타 사업자 만족도 97% |
| 한국신용데이터(캐시노트) | 배달앱·지도 리뷰 AI 감정분석·답글제안. 2026년 5월 출시 |

**처리** — "리뷰를 AI로 분석한다"는 것만으로는 차별점이 아니다. 신청서가 실제로 주장한 차별점은 **세 단계(분석→영상→확산)를 하나의 흐름으로 통합**하는 것이다. 발표에서 차별점을 말할 때 이 문장을 쓴다. 위 세 서비스가 하지 않는 것(여러 플랫폼 통합, 시계열 변화 추적, 경쟁점 대비 비교, 영상·인플루언서 연결)을 짚는다.

## 5. 판정을 바꿀 수 있는 경로 ★

리서치 리포트 §14가 지목한 **가장 먼저 해야 할 것**은 다음 둘이다.

- **G2** — 외식업자가 리뷰를 직접 확인·분석하는 데 쓰는 시간과 부담은 얼마인가
- **G9** — 안양시 외식업자의 실제 애로사항은 전국 통계와 같은가

> "이 둘은 Value Chain의 첫 번째·두 번째 단절 지점에 정확히 대응하며, **안양시 외식업자 10~20명 인터뷰라는 하나의 활동으로 동시에 검증할 수 있다.** 이 인터뷰 결과에 따라 프로젝트 가치 판정이 D에서 B 또는 C로 바뀔 수 있다."

**그런데 이 활동은 이미 신청서 ⑦ 3주차에 "지역 소상공인 5~10곳 인터뷰(현장조사)"로 약속돼 있다.**

즉 **신청서가 약속한 활동 = 리서치가 지목한 반전 경로**다. 이것이 중간간담회의 중심 서사가 될 수 있다.

### 판정 상향 조건

| → | 조건 |
|---|---|
| **B** (Pain은 맞지만 Solution 수정 필요) | 인터뷰에서 사장님이 리뷰 확인·대응에 실제 부담을 느끼고, 그 부담이 네이버 온서비스 AI로 해소되지 않는 부분(여러 플랫폼 통합, 시계열 변화 추적, 경쟁점 대비 비교)에 있음이 확인될 때 |
| **C** (특정 세그먼트에만 적합) | 그 부담이 특정 세그먼트(리뷰 100개 이상 중형 매장, 다점포 운영자, 신규 오픈 매장)에만 존재함이 확인될 때 |
| 데이터 리스크 해소 | 공식 API·제휴 경로가 열리거나, 사장님 본인 계정 연동 방식으로 수집 구조를 전환할 때 |
