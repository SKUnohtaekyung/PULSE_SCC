# PULSE 출시 전 법률·정책 검토 체크리스트

## 현재 판정

**법률 검토 미완료 / 운영 출시 차단**. `TERMS_OF_SERVICE.md`와 `PRIVACY_POLICY.md`는 구현용 초안이다. 아래 P0가 모두 닫히고 대한민국 변호사 또는 적격 개인정보 전문가의 서면 검토 결과를 반영하기 전에는 실제 가입·리뷰 수집·OpenAI 전송을 운영 환경에서 활성화하지 않는다.

## P0 — 출시 차단 항목

- [ ] 운영 법인/개인, 대표자, 주소, 사업자등록 및 통신판매업 해당 여부 확정
- [ ] 고객지원·개인정보 보호책임자·권리행사 채널 확정
- [ ] 만 14세 미만 가입 정책과 연령 확인/법정대리인 동의 필요 여부 확정
- [ ] 회원 탈퇴, 개인정보 열람·정정·삭제·처리정지 API와 운영 절차 구현
- [ ] 계정·동의·보안 로그·미저장 분석·백업별 정확한 보유기간 확정
- [ ] 리뷰 본문 내 우연한 개인정보·민감정보의 탐지, 비식별, 삭제 요청 절차 확정
- [ ] 네이버로부터 자동 수집의 명시적 승인 확보 또는 공식 API·robots 허용 범위로 설계 변경
- [ ] 네이버 약관·접근정책·리뷰 저작권 및 데이터베이스 권리 검토
- [ ] OpenAI 실제 계약 주체, API 데이터 사용 정책, 저장 기간, 처리 리전, 하위처리자 확인
- [ ] OpenAI 전송이 처리위탁·제3자 제공·국외 이전 중 무엇인지와 적용 법적 근거 확정
- [ ] 국외 이전 고지·동의 또는 다른 적법 근거, 거부 방법·효과, 보호조치 확정
- [ ] 유료화 여부에 따른 전자상거래법상 표시·환불·기록 보존 의무 검토
- [ ] 약관의 면책·이용제한·관할 조항이 약관법상 불공정하지 않은지 검토
- [ ] 개인정보 영향·위험평가와 침해사고 대응·통지 절차 수립
- [ ] 최종 문서 버전/시행일을 백엔드 `LegalDocuments` 및 앱 동의 화면과 동기화

## P1 — 운영 전 증빙

- [ ] 동의 UI가 목적·항목·보유기간·거부권/불이익을 분명히 보여주는지 검증
- [ ] `legal_consents`에 사용자, 문서 종류, 버전, 동의 시각이 정확히 저장되는지 통합 테스트
- [ ] 작성자 닉네임·프로필·원문 URL 등 식별정보가 DB·로그·프롬프트에 남지 않는지 표본 감사
- [ ] API 키·서비스 토큰·JWT 비밀의 저장, 회전, 접근권한과 사고 시 폐기 절차 검증
- [ ] 생성 이미지와 분석 결과에 AI 생성·참고용·비인구통계 안내가 유지되는지 QA
- [ ] 앱/웹의 SDK, 쿠키, SecureStore/localStorage 및 진단 로그의 실제 수집 항목 조사
- [ ] 삭제 요청 시 PostgreSQL, 이미지 파일, 로그, 백업, 외부 처리자 데이터 삭제 흐름 검증
