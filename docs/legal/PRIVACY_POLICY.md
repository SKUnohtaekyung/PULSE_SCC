## 3. 처리의 법적 근거와 동의

1. 계정과 서비스 제공에 필수적인 항목은 개인정보 보호법상 동의 또는 계약의 체결·이행에 필요한 범위인지 법률 검토 후 근거를 확정한다.
2. 동의를 근거로 수집할 때는 목적, 항목, 보유기간, 거부권 및 거부 시 불이익을 구체적으로 알리고 항목별로 선택할 수 있게 한다.
3. 현재 회원가입은 서비스 이용약관과 개인정보 수집·이용을 분리해 동의받고 문서 버전과 시각을 기록한다.
4. 마케팅·광고성 정보 수신은 현재 수집하지 않는다. 도입 시 선택 동의로 분리한다.

## 4. 공개 리뷰의 처리

1. 회원이 지정한 음식점의 공개 리뷰를 분석 목적으로 처리한다.
2. 중복·무효 리뷰를 제외하고 본문 해시를 이용해 같은 작업 안의 중복을 줄인다.
3. 공개된 정보라도 개인정보가 포함될 수 있으므로 작성자 식별정보는 제외하고, 리뷰 본문에 우연히 포함된 민감정보·개인 연락처를 탐지·최소화하는 절차는 **출시 전 추가 검토·구현**한다.
4. 정보주체 또는 권리자의 열람·삭제·처리정지 요청을 받을 절차와 원문 추적·삭제 범위는 **TBD**다.

## 6. 보유와 파기

1. 목적 달성 또는 보유기간 만료 시 지체 없이 복구하기 어려운 방법으로 파기한다.
2. 전자 파일은 안전한 삭제 방법으로, 출력물은 파쇄 또는 소각으로 파기한다.
3. 관계 법령에 따라 별도 보존해야 하면 해당 정보와 근거·기간을 분리 보관한다. 적용되는 전자상거래법상 기록 종류와 유·무료 서비스 해당 여부는 **법률 검토 후 확정**한다.
4. DB 삭제와 별도로 파일 시스템의 생성 이미지, 백업, 로그 및 외부 처리자의 사본까지 삭제되는 절차는 **출시 전 구현·검증**한다.
