# TASK-016 — 결과 화면 Design Synthesis

## Status

사용자 선택을 반영한 Step 5 합성안과 Android 실행 프로토타입을 준비했다. 이 문서는 선택 요소와 UX 근거의 정본이며, 프로토타입 코드는 실제 API·저장·인증이 없는 디자인 검증 도구다.

> 모든 상호명, 리뷰, 날짜, 수치는 가상 데이터다. 프로토타입을 실제 분석 결과로 사용하지 않는다.

## User-selected synthesis

| 영역 | 선택 | 적용 이유 |
|---|---|---|
| 전체 정보 구조 | A `Evidence Ledger` | 카드 하나가 판단 하나를 담당하고, 4가지 관점에서 근거로 바로 이어지는 흐름이 가장 분명하다 |
| 하단 내비게이션 | D 합성안의 가운데 원형 `분석하기` | `홈 → 분석하기 → 마이페이지` 순서와 중앙 주요 행동을 한눈에 구분한다 |
| 손님 유형 TOP3 | D 합성안의 음식 중심 이미지와 3칸 카드 | 사람의 성별·연령을 암시하지 않으면서 세 유형을 빠르게 비교할 수 있다 |
| 사실·행동·AI 순서 | RESULT_IA D10~D11 | 탐색안보다 정본을 우선해 리뷰 사실과 행동을 기본 노출하고 AI 해석·참고 지식은 접는다 |

사용자가 말한 `첫 번째`는 A의 화면 구조, `다섯 번째`는 합성안 계열의 하단 내비게이션으로 해석했다. 실행 프로토타입을 직접 확인한 뒤 이 해석이 다르면 해당 영역만 다시 합성한다.

## Final screen order

1. PULSE와 `실행 프로토타입 · 가상 데이터` 고지
2. 가게명, 분석 대상·리뷰 수·분석 시점
3. 분석 한계
4. 리뷰에서 많이 반복된 순서의 손님 유형 TOP3
5. 선택한 유형의 설명과 AI 생성 이미지 고지
6. 우선순위·긍정 신호·부정 신호·인식과 각 근거 진입점
7. 대표 근거 리뷰 2건과 전체 보기
8. 리뷰 사실 + 검토해 볼 행동
9. 접힌 AI 해석과 참고 지식
10. 고정 하단 내비게이션

## Interaction decisions

- TOP3는 접근 가능한 `tab`으로 구현하고 선택 상태를 테두리·배경·순위 배지로 함께 표현한다.
- TOP3 이미지에는 기능 중심 대체 텍스트를 제공하고 `AI 생성 이미지`를 화면에 표시한다.
- 근거 링크와 하단 내비게이션은 최소 44px 터치 영역을 사용한다.
- AI 해석과 참고 지식은 각각 독립 버튼이며 펼침 상태와 현재 행동(`펼쳐보기`/`접기`)을 보조기술에 제공한다.
- 참고 지식에는 시안용 출처 진입점을 두되, 실제 자료명·URL·검증일이 아직 연결되지 않았음을 안내한다.
- 중앙 `분석하기`의 원형 버튼은 주황색을 유지하고, 작은 라벨은 흰 배경에서 4.5:1 이상인 브랜드 텍스트 토큰을 사용한다.
- 제품으로 확정되지 않은 전체 근거·홈·분석·마이페이지 이동은 가짜 화면으로 연결하지 않고 프로토타입 안내를 표시한다.

## Rejected or deferred

- 사람 캐릭터와 인구통계적으로 보이는 페르소나 이미지
- C의 보라색, B의 번호 중심 장식, 근거 없는 비율·점수
- AI 해석을 펼친 채 행동보다 먼저 보여주는 순서
- 만족도·매출 개선을 보장하는 행동 문구
- 유형 부족, loading, empty, error, 인증, 저장, 실제 전체 근거 화면
- sticky TOP3: 이번 실행에서는 확정하지 않았다.

## Prototype boundary

실행 코드는 [ResultPrototype.tsx](../../../../frontend/mobile/src/prototypes/result/ResultPrototype.tsx)에 격리했다. 기본 진입점은 프로토타입이며 기존 디자인 토큰 화면은 `/foundation` 경로로 유지한다. `android.package`와 scheme을 만들지 않았기 때문에 Expo Go로만 실행한다.

제품 Vertical Slice로 승격하려면 최소 Android OS·지원 기기 범위·compact API/TalkBack 조합, 앱 package·scheme, D8·D12·D15 상태, 실제 데이터·출처 계약을 먼저 확정해야 한다.

## Run

Android 에뮬레이터를 실행한 뒤 `frontend/mobile`에서 다음 명령을 사용한다.

```powershell
npm exec expo start -- --go --android --port 8081
```

Expo Go의 회색 설정 버튼과 scheme 경고는 개발 도구 오버레이이며 앱 UI가 아니다.
