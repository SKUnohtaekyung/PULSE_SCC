# TASK-015 ImageGen 생성 조건·프롬프트 요약

이 문서는 실제 입력 원문 전체가 아니라 재현에 필요한 모드, 공통 제약, 방향별 의도와 후속 편집 내용을 요약한다.

## Mode

- A/B/C: `generate`
- D 초안: `generate` with A/B/C reference images
- D 최종본: `edit`; 행동 제안 문구를 교정한 뒤 사실+행동 기본 노출, AI·지식 접힘 순서로 재배치
- 독립 유통 안전 편집: 네 보드에 `디자인 탐색 · 시안용 가상 데이터` 라벨 추가, D의 우선순위 문구를 관찰 사실로 교정

## Shared Constraints

모든 시안은 다음 조건을 공유했다.

- Android 세로형 결과 화면 2개를 한 이미지에 나란히 제시
- PULSE 디자인 토큰의 파란색, 주황색, 중립색과 Pretendard 계열 한글 타이포 사용
- 순서: 메타데이터 → TOP 3 → 선택 유형 → 4가지 관점 → 근거 → AI 해석 → 행동
- TOP 3는 리뷰 수 순위이며 첫 항목이 기본 선택
- 사실·근거와 AI 해석을 구조적으로 구분
- 대표 근거 1~2개와 전체 근거 진입점 제공
- 하단 내비게이션은 홈·분석하기·마이페이지, 중앙 분석하기만 주황색 강조
- 성별·연령 등 인구통계 추정 금지, 과장된 마케팅 표현과 결과 보장 금지
- 결과는 탐색용 목업이며 제품 코드나 실제 분석 데이터가 아님

## A — Evidence Ledger

근거 추적을 최우선으로 하는 차분한 에디토리얼 방향. 4가지 관점 각각에 근거 수와 진입점을 붙이고, 이어지는 화면에서 대표 리뷰·AI 해석·행동 제안을 보여 주도록 요청했다.

## B — Guided Narrative

처음 사용하는 사람이 긴 결과를 순서대로 이해하도록 번호, 짧은 안내 문장, 점진적 공개를 강조했다. 정보 구조를 설명적으로 보여 주되 장식은 제한하도록 요청했다.

## C — Focused Comparison

TOP 3 비교와 4가지 관점의 빠른 스캔을 강조했다. 동일한 행 패턴, 좁은 화면에서의 압축성, 선택 상태의 명확성을 우선하도록 요청했다.

## D — Synthesis

A의 판단별 근거 링크, B의 평이한 읽기 안내, C의 압축된 TOP 3와 일관된 관점 행을 결합했다. 사람 페르소나 대신 음식·공간의 상징적 장면을 사용하고 `AI 생성 이미지` 라벨을 포함하도록 요청했다.

## Final Edits

첫 번째 편집에서는 합성안의 다른 요소를 유지하고, `검토해 볼 행동` 카드의 결과 보장 표현만 다음 문장으로 교체했다.

> 주말 등 혼잡 시간대의 반복 언급을 바탕으로, 방문 전에 예상 대기 정보를 확인할 수 있게 안내해 보세요.

`만족도를 높일 수 있어요`, `불편을 줄이고` 같은 효과 보장 표현은 남기지 않도록 명시했다.

재검토에서 AI 해석이 펼쳐진 채 행동보다 먼저 나온 점을 발견했다. 두 번째 편집에서는 왼쪽 화면과 전체 시각 체계는 유지하고 오른쪽 화면만 다음 순서로 고쳤다.

1. 대표 근거 2건
2. `리뷰에서 확인` 사실 + `검토해 볼 행동`
3. `AI 해석 펼쳐보기`
4. `참고 지식 펼쳐보기`

펼친 AI 본문은 제거하고 두 보조 레이어가 기본 상태에서 접혀 있도록 요청했다.

마지막 편집에서는 네 PNG가 문서와 분리되어도 실제 분석으로 오인되지 않게 보드 바깥 여백에 `디자인 탐색 · 시안용 가상 데이터`를 표시했다. D의 우선순위 설명은 고객 의도를 단정하지 않고 대기·혼잡 언급의 반복을 먼저 확인할 근거로 표현하도록 바꿨다.
