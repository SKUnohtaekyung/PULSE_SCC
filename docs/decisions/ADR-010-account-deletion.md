# ADR-010 — 계정 탈퇴와 연계 데이터 삭제

| | |
|---|---|
| Status | Accepted |
| Date | 2026-09-18 |
| 결정자 | `role:feature`, `role:platform` |

## Context

MVP에는 회원 탈퇴와 계정 연계 데이터 삭제 경로가 없었다. Access Token만으로 실수 또는 탈취 세션에서 자체 계정을 삭제하지 않도록 재확인이 필요하다.

## Decision

`DELETE /api/v1/me/account`를 제공한다. 자체 계정은 현재 비밀번호를 다시 확인하고, Google 전용 계정은 유효한 현재 인증 세션으로 본인을 확인한다. 성공 시 사용자, 로그인 식별자·세션·약관 동의, 분석 작업·리뷰·분석 결과·근거·저장 선택·알림과 파일 저장소의 페르소나 이미지를 삭제한다.

## Consequences

- 삭제 후 복구 기능은 제공하지 않는다.
- 자동 보관 기간과 법정 보존 예외는 법률 검토 후 별도로 확정한다.
- 파일 삭제 실패 시 DB 트랜잭션도 실패시켜 부분 완료를 숨기지 않는다.
