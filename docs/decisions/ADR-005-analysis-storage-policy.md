# ADR-005 — 계정당 분석 저장 1개와 세션 한정 결과

| | |
|---|---|
| Status | Accepted |
| Date | 2026-09-13 |
| 결정자 | 팀 (`role:product`) |
| 관련 요구사항 | [PRD.md](../product/PRD.md) FR-011 |

## Context

사용자는 가게 분석을 반복 실행할 수 있어야 하지만, MVP에서 복수 가게·분석 이력을 영구 관리하면 저장·목록·교체·비교 기능까지 범위가 커진다. 계정에 남길 분석과 일회성 분석을 구분할 필요가 있다.

## Decision

- 한 계정에는 **저장된 가게 분석 결과를 최대 1개**만 둔다.
- 저장본이 없을 때 완료된 첫 분석 결과는 자동 저장하고 홈에 표시한다.
- 저장본이 이미 있어도 다른 가게 또는 같은 가게의 새 분석을 실행할 수 있다.
- 새 분석이 완료되면 사용자가 **새 결과로 교체**하거나 **기존 결과 유지**를 선택한다.
- 새 결과로 교체하면 기존 저장본을 새 결과로 대체하되 계정의 저장 결과는 계속 1개로 유지한다.
- 기존 결과 유지를 선택하면 기존 저장본은 바꾸지 않고 새 결과는 저장하지 않는다. 미저장 새 결과의 세션 내 접근 범위와 최대 보관 시간은 미정이다.
- 앱이 재실행돼도 기존 인증 세션이 안전하게 복원된 경우에는 새 로그인으로 보지 않는다.
- 데이터베이스는 계정당 저장본이 1개를 넘지 않도록 서버 검증과 고유 제약으로 보장한다.

## Consequences

**가능해지는 것**

- 사용자는 저장 슬롯이 차 있어도 추가 분석을 실행하고 저장본 교체 여부를 직접 결정할 수 있다.
- MVP에서 복수 저장 목록과 월별 이력 관리를 만들지 않아도 된다.

**필요한 것**

- 첫 분석 결과 자동 저장 처리
- 교체와 기존 유지 선택을 반영하는 데이터 모델과 권한 검증
- 동시에 들어온 교체 요청에서도 1개 제한을 지키는 트랜잭션·고유 제약
- 기존 결과 유지 시 미저장 새 결과의 보관·삭제 처리

## Open Questions

- 한 계정의 동시 분석 작업 수 제한
- 기존 결과 유지 시 미저장 새 결과의 세션 내 접근 범위와 최대 보관 시간
