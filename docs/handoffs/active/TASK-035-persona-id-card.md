## Decisions

- **참고 이미지의 구성만 따르고 그림·글꼴·문구는 가져오지 않았다.** 다른 사람이 만든 디자인이고 실제 인물 사진이 들어 있다. 글꼴은 앱의 Pretendard, 색과 간격은 기존 토큰만 썼다.
- **신상 칸을 두지 않았다.** 참고 이미지의 생년월일·성별·눈 색·키는 리뷰로 알 수 없는 값이라 넣으면 지어낸 인구통계가 된다(PRD §7 규칙 2). 대신 리뷰에서 나온 값(순위·리뷰 수·비율)과 가게·분석한 날을 적는다.
- **지문·서명은 넣지 않았다.** 실제 사람의 것으로 읽힐 수 있다. 그림 바로 아래에 `AI 가상 인물`을 적었다(IMAGE-003). 목록 위의 기존 고지 문장도 그대로다.
- **줄무늬는 아무 값도 담지 않는 장식이다.** 바코드처럼 보이지만 읽히지 않는다. 카드마다 달라 보이도록 글자에서 굵기를 뽑는다. 화면 읽기 기능에는 숨겼다.
- **비율은 결과 화면과 같은 앱 계산값이다**: `round(유형 리뷰 수 ÷ 분석한 리뷰 수 × 100)`.
- **뒤집기는 절반 지점에서 앞뒤의 투명도를 바꾼다.** 뒷면 숨김(`backfaceVisibility`)은 Android에서 기기마다 달라 쓰지 않았다. 길이는 모션 토큰 `reveal`(300ms), 모션 감소 설정에서는 바로 바뀐다.
- **카드 높이는 고정하지 않았다.** 최소 높이만 신분증 비율(85.6:53.98)로 두고, 글자가 커지면 칸이 다음 줄로 넘어가며 카드가 길어진다. 뒷면은 앞면 크기를 그대로 덮는다.
- 새 토큰을 만들지 않았다. 카드는 마이페이지에서만 써서 공용 컴포넌트로 올리지 않았다.

실패했다가 고친 것:

- 뒷면 워드마크를 `width: '56%'`와 `aspectRatio`로 줬더니 Android에서 원본 크기로 그려져 카드를 넘쳤다(캡처로 확인). 카드 폭에서 계산한 숫자 크기로 바꿨다.
- 글자 200%·가로 1280dp에서 `가게` 칸이 한 글자씩 세로로 쪼개졌다. 칸이 줄바꿈되게 하고 `가게` 칸에 최소 폭을 줬다.
- PULSE 심볼을 화면 읽기 기능에서 숨겼던 것을 풀고 카드 이름에 `PULSE`를 넣었다(브랜드 에셋 규칙: 대체 텍스트 `PULSE`를 숨기지 않는다).

## Unresolved

- 실제 태블릿에서 보지 않았다.
- 화면이 1024dp 경계를 넘어 돌거나 크기가 바뀌면 카드가 새로 그려져 뒤집어 둔 카드가 앞면으로 돌아간다(TASK-033과 같은 원인).
- 원격 이미지를 받는 동안에는 자리표시 그림 아래에 잠깐 `AI 가상 인물`이 보인다. 카드는 불러오기가 끝났는지까지는 알지 못한다.
- 줄무늬 장식의 색으로 글자색 토큰(`colors.text.strong`)을 썼다. 새 색은 아니지만 용도가 달라 `role:design-system` 확인이 필요하다.
- 뒤집을 때 화면 읽기 기능에 어느 면인지 알리도록 했으나 TalkBack으로 들어 보지 않았다.
- 위 Visual QA 행의 미확인 항목.
- 시험에 쓴 가게 이름이 영문(`UnsanGukbap`)이라 한글 가게 이름의 줄바꿈은 보지 않았다. 가게 이름은 한 줄로 자르고 넘치면 말줄임표가 붙는다.
- 그림을 누르면 크게 보던 동작이 버튼으로 옮겨졌다. 카드 아래 버튼이 두 개가 돼 카드 피드가 길어졌다.
- 참고 이미지처럼 화려한 제목 글꼴·색은 쓰지 않았다. 앱의 글꼴과 남색만 썼다. 더 닮게 하려면 새 글꼴 에셋과 토큰이 필요하다.

## Do Not Assume

- Android에서 `Image`에 비율(%) 폭과 `aspectRatio`만 주면 원본 크기로 그려질 수 있다. 숫자로 준다.
- 카드에 사람의 신상 칸을 더하지 않는다. 리뷰로 알 수 없는 값이다.
