## Decisions

1. **원본 엑셀(137.9KB)을 저장소에 커밋하지 않았다.** `research/` 의 기존 관행이 `.md` + `evidence_registry.csv` 뿐이다. 출처 URL과 §2 표로 재현 가능하다.
2. **`_gap_anyang.md` 의 본문 수치는 수정하지 않고 정정 주석만 달았다.** 조사 시점의 Agent 산출 기록이므로 소급 수정하면 이력이 흐려진다. 오류는 파일 설명문에만 있다.
3. **`PROBLEM_BASELINE.md`(role:product 소유)를 직접 갱신했다.** 담당자 미배정이고, 해당 문서 §2.4가 "발표 전에 반드시 확인한다"고 스스로 지시한 항목을 채우는 것이다. PR 본문에 명시하고 role:product를 리뷰어로 지정한다.
4. **`SCC_중간발표.pdf`(35MB, 팀원 실명 4명 포함)는 건드리지 않았다.** 이번 작업 범위 밖이며 `AGENTS.md` 6.3에 따른다. untracked 유지. 대신 이 PDF를 근거로 삼은 서술에는 "저장소 외부 자료" 주석을 달았다.
5. **위키백과 기반 서술을 근거에서 전부 제거했다.** `rejected_sources.md` 가 위키를 전면 배제하므로, "명학역이 3개 동 경계에 있다"는 초안의 결론을 철회하고 **"행정동 미확정"** 으로 되돌렸다. (Reviewer FAIL 1)
6. **모든 수치에 KSIC 분류(56 / 561)를 병기했다.** 56과 561은 순위가 재배열된다(안양6동 7위↔10위, 안양7동 9위↔7위). 분류 없이 인용하면 최대 2배 과대 해석된다. (Reviewer FAIL 2)

2. **"명학역 인근"의 공식 정의가 팀에 없다.** 명학동만인지, 안양6·7동을 포함하는지에 따라 숫자가 크게 달라진다

5. 박달1동→박달동, 박달2동→호현동 개칭의 공식 시행일 미확인
6. 동별 폐업률·유동인구는 사업체조사에 없다. 별도 자료원 필요
