4. **`SCC_중간발표.pdf`(35MB, 팀원 실명 4명 포함)는 건드리지 않았다.** 이번 작업 범위 밖이며 `AGENTS.md` 6.3(작업과 무관한 파일 동시 수정 금지)에 따른다. untracked 상태 유지.
