# 중간발표 슬라이드 시안

**이 폴더는 초안이다.** Figma에서 직접 수정하는 것을 전제로 만들었고, 여기 파일은 출발점이다.
최종 발표 자료의 정본은 팀 Figma 파일이며 이 폴더가 아니다.

| | |
|---|---|
| 작성 | 2026-08-23 |
| 캔버스 | 1920 × 1080 (Figma Slides 기본값) |
| 폰트 | Noto Sans KR |
| 소유 역할 | `role:product` |

---

## 폴더

```
docs/presentation/
├─ README.md      이 문서
├─ svg/           Figma에 넣을 파일 11장
├─ preview/       어떤 안인지 눈으로 고르기 위한 PNG
└─ generate.py    svg/ 를 만든 스크립트 (수치가 바뀌면 여기서 다시 뽑는다)
```

**Figma에 넣는 법** — `svg/` 의 파일을 캔버스로 드래그하거나 `File > Import`.
제목·본문·라벨은 편집 가능한 텍스트 레이어로, 막대·점·카드는 벡터로 들어간다.
오토레이아웃은 붙지 않는다(SVG에 레이아웃 개념이 없다). 필요하면 Figma에서 감싼다.

## 슬라이드 목록

### A. 기존 p5 수정안 — 모집단 혼용 오류를 고친 3안

원래 p5는 대형 숫자에 **안양시 사업체수(7,173)** 와 **만안구 종사자수(8,345)** 를 한 블록에 넣었고
부제는 만안구 사업체수(3,175)를 썼다. 한 장에 두 모집단이 섞여 있었다.

| 파일 | 접근 |
|---|---|
| `A-1_문제정의_만안구통일` | 대형 숫자를 만안구로 통일. 전국 지표에 회색 `전국` 태그. **원안에서 가장 적게 움직인다** |
| `A-1b_문제정의_판로개척회색` | A-1과 동일하되 **판로개척 3.4% 강조를 뺀** 버전. 아래 "선택이 남은 것" 참조 |
| `A-2_문제정의_좁혀들어가기` | 전국 793,082 → 안양시 7,173 → 만안구 3,175 → 일대 711을 중첩 깔때기로. 모집단 혼동이 구조적으로 불가능 |
| `A-3_문제정의_좌우분리` | 세로선으로 왼쪽 안양 전수 / 오른쪽 전국 표본을 물리적으로 분리 |

### B. 안양 데이터 신규 슬라이드 — 3안

덱에 안양이 배경 숫자로만 있어 "왜 안양인가"에 답이 없었다. 그 자리를 채운다.

| 파일 | 앞세우는 것 |
|---|---|
| `B-1_안양_31개동순위` | **위치** — 31개 동을 순위대로 세우고 우리 3개 동만 칠한다 |
| `B-2_안양_711개규모` | **규모** — 검증할 가게가 충분하다 |
| `B-3_안양_업체당종사자` | **영세성** — 명학역 일대 2.58명 vs 범계동 4.88명 |

### C. MVP 범위 슬라이드 — 2안

PRD에서 홍보영상·인플루언서 매칭이 Non-Goals가 됐는데 덱 p16·p19에 릴스 UI가 그대로 있다.
설명 없이 두면 "약속한 걸 안 만들었다"로 읽힌다.

| 파일 | 말하는 방식 |
|---|---|
| `C-1_범위_하는것안하는것` | 좌우 대비. 제외 항목마다 이유 한 줄 |
| `C-2_범위_순서를정했습니다` | 로드맵 + "왜 이 순서인가" + "이 로드맵에 없는 것". **현재 p22를 대체하면 슬라이드 수가 안 는다** |

### D. 진행상황 — 2안 (한 세트)

| 파일 | 역할 |
|---|---|
| `D-1_진행상황_파이프라인진척` | **어디까지 왔나** — 5단계 중 3단계 동작. 만든 것 / 결정한 것 / 아직 없는 것 |
| `D-2_진행상황_산출물` | **그래서 뭐가 나오나** — 리뷰 59건 → 손님 유형. 한계 4줄 선제 고지 |

D-1과 D-2는 나눠 쓰는 것이 아니라 **두 장이 한 흐름**이다. D-1이 주장, D-2가 증거다.

## 추천 조합

**`A-1` + `B-3` + `C-2` + `D-1` + `D-2`**

C-2가 기존 p22를 대체하므로 순증은 B-3·D-1·D-2 세 장이다.

B-3을 고른 이유는 셋이다.

1. **슬라이드 안에 "그래서 뭐"가 들어 있다.** B-1·B-2는 사실 진술에서 끝나는데 B-3은 *2.6명 → 마케팅에 쓸 사람도 시간도 없다 → 입력 부담 없는 도구가 필요하다* 까지 한 장에서 이어진다.
2. **지금 없는 자료에 기대지 않는다.** B-2는 인터뷰 수가, B-1은 "왜 거기냐"에 대한 답이 있어야 성립한다.
3. **덱 p9 TARGET을 떠받친다.** 현재 p9의 페르소나는 근거가 없는 카드인데, B-3이 앞뒤에 오면 "평균 2.6명이 굴리는 가게 → 그래서 이 사장님"으로 연결된다.

B-1은 질의응답에서 "안양 어디냐"가 나올 때 꺼내는 **백업**, B-2는 **인터뷰 수가 확보되는 순간** 가장 강해진다.

## 발표에서 지킬 것

슬라이드만 넘기면 빠지는데, 여기가 반박당하는 지점이다.

**1. KSIC 분류를 반드시 밝힌다.**
`56`(음식점 + 주점업)과 `561`(음식점업 단독)은 순위가 재배열된다. 안양6동은 56 기준 361개지만 561 기준 177개로 **약 2배 차이**다.

**2. 업체당 종사자 수는 계산값이다.**
종사자수 ÷ 사업체수로 구한 값이며 원자료 공표값이 아니다.

**3. "명학역 일대가 유별나게 영세하다"고 말하지 않는다.**
명학역 일대 2.58명과 만안구 전체 2.63명은 사실상 같다. 대신 **"만안구 전체가 같은 성격이라 검증 범위를 넓혀도 만나는 매장 유형은 같다"** 로 쓴다 — 표본 대표성 논리가 되면서 "왜 하필 그 동네냐"를 무력화한다.

**4. 명학역 지번의 행정동은 아직 확정되지 않았다.**
확정된 것은 성결대학교가 명학동 관할이라는 사실뿐이다(만안구청 공식 페이지). **"명학역이 속한 동"이 아니라 "성결대가 있는 명학동"** 으로 말한다.

**5. 행정동 명칭이 바뀌었다.**
2026-07-01부로 안양8동 → 명학동. 2024년 통계표는 옛 이름을 쓰므로 **"명학동(구 안양8동)"** 으로 병기한다.

**6. MVP 범위를 넘는 표현을 쓰지 않는다.**
"켜두면 알아서 돌아간다", "모니터링", "변화 추적", "경영 플랫폼" — 월별 추적은 4단계, 추가 데이터 입력은 2단계다. 강조할 것은 **"사장님이 새로 만들 자료가 없다"** 이다.

## 선택이 남은 것

**1. `A-1` vs `A-1b` — 판로개척 3.4%를 오렌지로 강조할지**

강조하면 "우리가 겨냥한 항목이 여기 있고 우리도 낮다는 걸 안다"가 되지만, 6개 중 가장 작은 막대에 시선이 간다. **인터뷰 숫자를 말할 수 있으면 A-1**(통계는 3.4%인데 우리가 만난 N명은 달랐다 → 다음 장이 반전), **말할 수 없으면 A-1b**.

**2. `B-3` 제목의 "굴린다"**

지금은 *"우리가 만나는 가게는 평균 2.6명이 굴린다"* 인데 어감이 거칠고 부제(습니다체)와 문체가 어긋난다. 대안: **꾸립니다**(추천) / 전부입니다 / 맡습니다 / 명사 종결.

**3. `D-2`의 숫자**

덱 p14 터미널 로그에서 읽은 값이다. 로그가 실제로 말하는 것은 *"topic info를 59건에 추가"* 와 *상위 4개 유형의 이름·비율* 까지다. **수집 총건수·전체 토픽 수·매장 수는 로그에 없어 슬라이드에서 뺐다.** 파이프라인을 다시 돌려 확정하면 이 슬라이드가 훨씬 강해진다.

## 수치를 다시 뽑을 때

`generate.py` 상단의 데이터 상수(`RANK`, `PAIN`, `COST`)와 각 슬라이드 함수 안의 값을 고치고 실행하면 `svg/` 가 다시 만들어진다.

```bash
python docs/presentation/generate.py
```

레이아웃은 `cqw` 기준(1cqw = 19.2px)으로 짜여 있어 1920 폭에서 그대로 환산된다.
